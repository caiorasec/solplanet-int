# Home Assistant Solplanet Integration

Custom component para integrar inversores **Solplanet (AISWEI)** no Home Assistant.

## Funcionalidades
- Potência atual (W)
- Energia do dia (kWh)
- Energia total acumulada (kWh)
- Compatível com o Energy Dashboard

## Instalação
1. Copie `custom_components/solplanet` para sua pasta `config/custom_components/`.
2. Reinicie o Home Assistant.
3. Vá em Configurações → Integrações → Adicionar → Solplanet.
4. Preencha usuário, senha e Plant ID.
